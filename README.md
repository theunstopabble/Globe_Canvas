# Globe Canvas

[Live Demo](https://globe-canvas-theunstopabble.netlify.app/)

## About

Globe Canvas is a lightweight web project showcasing an interactive, visually appealing globe visualization built purely with HTML. Perfect for adding dynamic geographic elements to your web projects.

## Features

- Interactive globe canvas rendering
- Minimalistic and clean codebase
- Fast loading and responsive design
- Easy to integrate and customize

## Technologies Used

- HTML
- css
- js

## Getting Started

### Prerequisites

A modern web browser is all you need to run this project locally or in production.

### Installation

1. Clone the repository:
git clone https://github.com/theunstopabble/Globe_Canvas.git
2. Open `index.html` in your browser or serve via any static file server.

## Usage

Simply open the `index.html` to see the globe canvas animation in action. Modify the HTML file to customize or extend functionality as needed.
